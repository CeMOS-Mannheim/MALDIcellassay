# Check if object if of class MALDIassay

Check if object if of class MALDIassay

## Usage

``` r
isMALDIassay(object)
```

## Arguments

- object:

  object to text

## Value

logical, TRUE if object is of class MALDIassay

## Examples

``` r
x <- 1
# FALSE
isMALDIassay(x)
#> [1] FALSE
# TRUE
isMALDIassay(Blank2022res)
#> [1] TRUE
```
